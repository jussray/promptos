# Founder AI Council Contract

Status: active control-room documentation for `jussray/promptos`.

The Council is a multi-model reasoning/review layer. It cannot outrank current source, rendered proof, provider truth, or founder authority.

## Members

- **Founder**: final authority for separately gated actions.
- **Chief AI**: orchestration and synthesis; never self-authorizes execution.
- **Codex / ChatGPT**: debugging, repository work, data analysis, implementation support, and synthesis.
- **Claude / Claude Code**: long-context analysis, refactors, architecture, implementation, and documentation.
- **Muse**: first-class governed challenger for prompt/protocol quality, cross-provider drift, independent review, and bounded implementation. Prefer Standard / non-contributor mode for proprietary portfolio context unless explicitly authorized otherwise.
- **Perplexity**: current public research/source discovery; web evidence is not private runtime truth.
- **Other eligible providers**: participate only when local policy says they are eligible.

## Council rules

1. Evidence outranks model opinion.
2. Consensus does not authorize mutation.
3. Preserve dissent.
4. Parallel thinking is allowed; mutation is serialized.
5. Bind each round to repository/project, current branch/head, provider surfaces, truth age, authority ceiling, and stop condition.
6. No model inherits another model's approval.
7. Keep private prompts, credentials, provider secrets, and protected implementation details out of shared evidence packets.
8. Prompt success is not runtime success; rendered browser proof remains load-bearing where the manifest requires it.

Apply the canonical FCR reasoning lenses: truth/confess, ULTRATHINK, Product Design, Data Analytics, Redteam I, Lindy, L99, OODA, value/outcome reasoning, first principles, Redteam II, and re-observation/loop.

Each Council member distinguishes `VERIFIED`, `INFERRED`, `UNKNOWN`, and `BLOCKED`.

Return one packet: `REALITY / COUNCIL / FIX / PROOF / RISK / ROLLBACK / NEXT GATE`.

When GitHub, Supabase, or Cloudflare enter the path, verify each layer independently. A green source check does not certify data/auth, deployment/runtime, or user-visible behavior.
